Мыслик 2.0.1 beta
====================================
Личное пространство для мыслей: задачи, заметки и доски на одном холсте-паутине.

КАК ЗАПУСТИТЬ
--------------------
1. Распакуйте папку "Myslik" целиком в любое удобное место.
2. Запустите Myslik.exe (двойной клик).
   * Windows может показать синее окно "Система Windows защитила ваш компьютер".
     Нажмите "Подробнее", затем "Выполнить в любом случае".
3. Готово.

ГДЕ ХРАНЯТСЯ ВАШИ ДАННЫЕ
--------------------
* Всё лежит в папке  data\  рядом с Myslik.exe (data\planner.json + data\backups\).
* Чтобы перенести/забэкапить — скопируйте ВСЮ папку "Myslik" вместе с data.
* НЕ удаляйте папку  _internal  — без неё программа не запустится.

ОБНОВЛЕНИЕ
--------------------
* Настройки (шестерёнка внизу слева) -> раздел "Обновления" -> "Проверить обновления".
* Если вышла новая версия — кнопка "Обновить": приложение само скачает её, обновится
  и перезапустится. Ваши данные (папка data) при этом не трогаются.

ЧТО НОВОГО В 2.0
--------------------
* Полотно теперь доска Excalidraw: рисуйте от руки, фигуры, стрелки с привязкой,
  подписи рукописным шрифтом, картинки. У каждого полотна своя доска.
  Схемы из прошлых версий переносятся на доску сами, при первом открытии.
* Рабочая область поделена надвое: слева паутина, справа карточка выбранной ноды.
  Разделитель тянется мышью. Всё правится прямо в карточке, без отдельных окон.
* Левое меню стало полосой значков; кнопка вверху разворачивает подписи.
* Срочность видна прямо в паутине: у важных задач цветная "шапочка" над нодой.

С ЧЕГО НАЧАТЬ
--------------------
* Сверху — быстрый захват: бросьте мысль и Enter. Понимает #область/#тег, даты
  (завтра/пн/25.06), каждый день, !приоритет, *заметка.
* "Заметки" — граф-паутина: клик по ноде показывает её справа; ПКМ — создать
  (заметка, задача, полотно, область); Alt+тащить от ноды — связь; колесо — зум.
* Двойной клик по ноде-полотну открывает доску на весь экран.
* Клик по области слева подсвечивает её ноды в паутине.
* Остальные виды (Сегодня, Задачи, Папки, Календарь) — через Ctrl+K или цифры 1-6:
  они ждут переработки и пока убраны из меню.

ЭКСПОРТ / ИМПОРТ / TELEGRAM
--------------------
* Внизу слева: стрелка вниз — сохранить в файл, стрелка вверх — загрузить.
* Бэкап и тема — в Настройках.
* Захват мыслей с телефона: заведи бота у @BotFather, вставь токен в Настройки ->
  Telegram, пиши боту, забрать сообщения — из палитры команд (Ctrl+K).

ТРЕБОВАНИЯ
--------------------
* Windows 10/11 (64-бит) + Microsoft Edge WebView2 Runtime (обычно уже есть;
  иначе бесплатно: https://developer.microsoft.com/microsoft-edge/webview2/ , x64).
