# Мыслик

Личное пространство для мыслей: задачи, заметки и схемы на одном холсте-паутине.
Десктопное приложение для Windows, работает офлайн, все данные — локально рядом с программой.

## Возможности

- **Быстрый захват** — брось мысль сверху и Enter. Понимает `#область/#тег`, даты (`завтра/пн/25.06`), `каждый день`, `!приоритет`, `*заметка`.
- **Сегодня** — кольцо дня, серия, ритм недели, баланс областей.
- **Заметки** — граф-паутина: наведи на ноду — подсветятся соседи; колесо — зум; фон-звёзды с параллаксом. Есть режим «Список».
- **Полотно** — доска для рисования от руки на движке Excalidraw, на весь экран: фигуры, стрелки с привязкой, подписи рукописным шрифтом, картинки. У каждого полотна своя доска, сохраняется сама, уезжает вместе с экспортом, тему берёт из приложения. Схемы, нарисованные прежним редактором, переносятся на доску при первом открытии.
- **Обновления** — приложение само проверяет, не вышла ли новая версия, и показывает плашку справа внизу. Плашка не пропадает сама: либо жмёшь «Обновить» (скачается и перезапустится), либо закрываешь крестиком.
- **Статусы ноды** — «в работе» (нода светится своим цветом), «на паузе» (серый пунктир и слабое серое свечение: видно, что работа стоит, но глаз не цепляет как активную) и «готово». Ставятся из меню ноды по правой кнопке и применяются сразу ко всему выделению — выдели несколько нод, ткни правой по одной, нажми «В работу» или «На паузу».
- **Поля ноды** — кроме общего описания у заметки и задачи бывают именованные поля: текст, картинка, врезка доски. Раскладка как в Notion: строка делится на колонки, а внутри колонки плашки лежат друг под другом. Тащишь плитку за любое место: бросил на левый или правый край соседа — встала колонкой рядом, бросил в середину — встала выше или ниже него в той же колонке (так и кладут вторую плашку под первую), бросил ниже всех строк — уехала своей строкой. Ширину тянешь за разделитель между колонками (и за правый край строки, если плитка в ней одна), высоту — за нижнюю кромку плитки; текст и название правятся двойным кликом; содержимое копируется правой кнопкой (текст — текстом, картинка и доска — картинкой). Картинка кладётся перетаскиванием из проводника или вставкой из буфера — наведи курсор на врезку и нажми Ctrl+V (годится и снимок экрана), на доске рисуют прямо во врезке — она поднимается сама (в узком окне разворачивается на весь экран).
- **Шаблоны нод** — «разбор бага» с двумя текстовыми полями и схемой, «съёмка» с референсом. Отмеченный звёздочкой применяется ко всем новым нодам; готовую ноду можно заполнить по шаблону в любой момент. Шаблон не выбран — нода создаётся как раньше, с одним описанием.
- **Папки** — привязка папок проектов на ПК, открытие в проводнике одним кликом.
- **Задачи** — иерархия с фильтром; инбокс раскидывается по областям кликом.
- **Календарь** — перетаскивание задач по дням, призраки повторов.
- **Telegram** — захват заметок с телефона через своего бота.
- **Обновление из приложения** — Настройки → Обновления → «Проверить обновления».

## Установка (для пользователя)

1. Скачай архив из [релизов](https://github.com/Krolik5555/myslik/releases/latest), распакуй папку `Myslik` целиком.
2. Запусти `Myslik.exe`. Windows может показать «защита компьютера» — «Подробнее» → «Выполнить в любом случае».
3. Данные хранятся в `data\` рядом с exe. Чтобы перенести — копируй всю папку.

Требуется Windows 10/11 x64 + Microsoft Edge WebView2 Runtime (обычно уже есть).

## Стек

Python + [pywebview](https://pywebview.flowrl.com/) (WebView2) — нативное безрамочное окно.
Интерфейс — vanilla HTML/CSS/JS без сборки (`ui/`), модули грузятся классическими `<script>`.
Данные — `data/planner.json` + авто-бэкапы в `data/backups/`.

## Сборка из исходников

```powershell
# зависимости
py -3.12 -m venv .venv
.\.venv\Scripts\pip install pywebview pystray pillow pywin32 pyinstaller

# запуск в дев-режиме
.\.venv\Scripts\python app.py

# портативный exe -> release\Myslik\
.\.venv\Scripts\python -m PyInstaller --noconfirm --distpath release --workpath build Myslik.spec
```
