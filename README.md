# Мыслик

Личное пространство для мыслей: задачи, заметки и схемы на одном холсте-паутине.
Десктопное приложение для Windows, работает офлайн, все данные — локально рядом с программой.

## Возможности

- **Быстрый захват** — брось мысль сверху и Enter. Понимает `#область/#тег`, даты (`завтра/пн/25.06`), `каждый день`, `!приоритет`, `*заметка`.
- **Сегодня** — кольцо дня, серия, ритм недели, баланс областей.
- **Заметки** — граф-паутина: наведи на ноду — подсветятся соседи; колесо — зум; фон-звёзды с параллаксом. Есть режим «Список». Выделенное двигается пачкой: выдели ноды рамкой или с Shift и тяни любую из них — остальные едут следом. С зажатым Ctrl та же протяжка не двигает, а копирует: под рукой оказываются копии выделенного вместе со связями между ними, а оригиналы остаются на месте.
- **Полотно** — доска для рисования от руки на движке Excalidraw, на весь экран: фигуры, стрелки с привязкой, подписи рукописным шрифтом, картинки. У каждого полотна своя доска, сохраняется сама, уезжает вместе с экспортом, тему берёт из приложения. Схемы, нарисованные прежним редактором, переносятся на доску при первом открытии.
- **ИИ-агент управляет планером сам** — Claude Code и другие агенты умеют читать твой граф и создавать в нём ноды напрямую, без копипаста. Включается в Настройках одним переключателем, там же кнопка «Скопировать промпт для Claude»: отдаёшь текст агенту, и он настраивает себя сам — путь к твоей установке и ключ уже подставлены. Ставить ничего не нужно: сервер живёт внутри самого приложения, ни Python, ни отдельных пакетов не требуется. По умолчанию доступ выключен, работает только на этом компьютере и только с ключом; удаления агент делает лишь по отдельному разрешению, а каждое его действие показывается сообщением с кнопкой «Вернуть».
- **Общение с нейросетью** — Мыслик умеет принимать команды от любого ИИ, даже если тот ничего о нём не знает. Жмёшь «Скопировать промпт» (в меню «…» на графе или через Ctrl+K) — в буфер уходит описание формата вместе со снимком твоего графа. Отдаёшь это ChatGPT, Claude или чему угодно вместе со своей просьбой — «разбей проект на этапы», «расставь сроки», «добавь чек-лист» — и вставляешь ответ обратно. Приложение показывает списком, что именно будет сделано: какие ноды создать, что связать, где поменять статус. Ничего не произойдёт, пока не нажмёшь «Выполнить», удаления спросят отдельно, а весь пакет отменяется одним Ctrl+Z или кнопкой в сообщении. Никакого кода нейросеть не выполняет: приложение понимает только свой список команд и всё остальное отвергает.
- **Подграф** — нода, внутри которой лежит свой граф. Снаружи это обычная нода-шестиугольник: её связывают с чем угодно, дают ей теги, описание, поля и срок, её можно завершить. Двойной клик — и ты внутри: холст, где живут только её ноды и связи, а в центре стоит корневой узел с названием самого подграфа. Он не удаляется — это и есть обозначение подграфа, и от него строится дерево: свяжи с ним ноду, и она станет верхним уровнем, всё остальное выстроится под ней. Двойной клик по корню выводит наружу, правая кнопка даёт переименовать (имя тут же меняется и у самой ноды снаружи). Над холстом появляется дорожка «Мой граф › Проект › Этап» — клик по любому звену выводит на этот уровень, стрелка слева уводит на шаг вверх, Escape — тоже. Подграфы вкладываются друг в друга. Областей внутри нет намеренно: подграф раскрывает одну мысль, а области делят граф целиком. Удаление ноды уносит её содержимое, копия ноды получает свою собственную копию всего, что внутри; Ctrl+Z возвращает и то, и другое.
- **Несколько графов** — в левой панели сверху список графов, снизу области текущего. Кнопка «+» заводит новый граф: он пустой и полностью независимый — свои ноды, свои области, свои связи. Клик переключает, правая кнопка открывает настройки графа — имя, значок, цвет и удаление. Значок помогает не путать графы между собой в свёрнутой полосе.
- **Срок** — своя, а не системная, выпадашка календаря: месяц одной сеткой, сегодня в кольце, точка под днём, на который уже что-то назначено. Быстрые кнопки «сегодня / завтра / +нед» и крестик «снять срок» прямо в поле. Колесо листает месяцы, стрелки ходят по дням, Enter выбирает, Escape закрывает календарь (окно правки при этом остаётся).
- **Длина связи** — правая кнопка по линии открывает её настройки с ползунком длины. Работает и для нити от ноды к её области: можно подтянуть ноду ближе к центру области или отпустить подальше.
- **Удаление без корзины** — удалил, значит удалил: подтверждать дважды не нужно. Вернуть можно сразу — Ctrl+Z или кнопка «Вернуть» в всплывающем сообщении; нода возвращается вместе со связями, картинками и досками.
- **Обновления** — приложение само проверяет, не вышла ли новая версия, и показывает плашку справа внизу. Плашка не пропадает сама: либо жмёшь «Обновить» (скачается и перезапустится), либо закрываешь крестиком.
- **Статусы ноды** — «в работе» (нода светится своим цветом), «на паузе» (серый пунктир и слабое серое свечение: видно, что работа стоит, но глаз не цепляет как активную) и «готово». Ставятся из меню ноды по правой кнопке и применяются сразу ко всему выделению — выдели несколько нод, ткни правой по одной, нажми «В работу» или «На паузу».
- **Поля ноды** — кроме общего описания у заметки и задачи бывают именованные поля: текст, картинка, врезка доски. Раскладка как в Notion: строка делится на колонки, а внутри колонки плашки лежат друг под другом. Тащишь плитку за любое место: бросил на левый или правый край соседа — встала колонкой рядом, бросил в середину — встала выше или ниже него в той же колонке (так и кладут вторую плашку под первую), бросил ниже всех строк — уехала своей строкой. Ширину тянешь за разделитель между колонками (и за правый край строки, если плитка в ней одна), высоту — за нижнюю кромку плитки; текст и название правятся двойным кликом; содержимое копируется правой кнопкой (текст — текстом, картинка и доска — картинкой). Картинка кладётся перетаскиванием из проводника или вставкой из буфера: открыл ноду и нажал Ctrl+V — картинка заводит себе поле сама (годится и снимок экрана); наведи курсор на готовую врезку — уедет в неё. В правой панели вставка работает так же — курсор достаточно держать над самой панелью, в любом её месте (на холсте Ctrl+V вставляет скопированные ноды, поэтому туда жест не лезет). Плитка сама держит размер картинки: меняешь ширину — высота едет следом, картинка всегда видна целиком, без пустых полей и обрезки. Это режим «по размеру», он включён сразу; выключается кнопкой в полосе поля или просто протяжкой нижней кромки — тогда высоту задаёшь ты. На доске рисуют прямо во врезке — она поднимается сама (в узком окне разворачивается на весь экран).
- **Шаблоны нод** — «разбор бага» с двумя текстовыми полями и схемой, «съёмка» с референсом. Отмеченный звёздочкой применяется ко всем новым нодам; готовую ноду можно заполнить по шаблону в любой момент. Шаблон не выбран — нода создаётся как раньше, с одним описанием.
- **Папки** — привязка папок проектов на ПК, открытие в проводнике одним кликом.
- **Задачи** — иерархия с фильтром; инбокс раскидывается по областям кликом.
- **Календарь** — перетаскивание задач по дням, призраки повторов.
- **Telegram** — захват заметок с телефона через своего бота.
- **Обновление из приложения** — Настройки → Обновления → «Проверить обновления».

## Установка (для пользователя)

1. Скачай архив из [релизов](https://github.com/Krolik5555/myslik/releases/latest), распакуй папку `Myslik` целиком.
2. Запусти `Myslik.exe`. Windows может показать «защита компьютера» — «Подробнее» → «Выполнить в любом случае».
3. Данные хранятся в `data\` рядом с exe. Чтобы перенести — копируй всю папку.

Требуется Windows 10/11 x64 + Microsoft Edge WebView2 Runtime (обычно уже есть).

## Стек

Python + [pywebview](https://pywebview.flowrl.com/) (WebView2) — нативное безрамочное окно.
Интерфейс — vanilla HTML/CSS/JS без сборки (`ui/`), модули грузятся классическими `<script>`.
Данные — `data/planner.json` + авто-бэкапы в `data/backups/`.

## Сборка из исходников

```powershell
# зависимости
py -3.12 -m venv .venv
.\.venv\Scripts\pip install pywebview pystray pillow pywin32 pyinstaller

# запуск в дев-режиме
.\.venv\Scripts\python app.py

# портативный exe -> release\Myslik\
.\.venv\Scripts\python -m PyInstaller --noconfirm --distpath release --workpath build Myslik.spec
```
