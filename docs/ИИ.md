# ИИ в «Мыслике»

Два применения: **умный захват** (мысль → чистый заголовок, срок, срочность, вид) и **отчёт из
выделенного**. По умолчанию ИИ **выключен**, включается в Настройках.

Философия: **предлагает, не перекраивает.** Нода создаётся мгновенно обычным разбором строки,
а через ~1.5 с рядом всплывает бледная карточка «Понял так». Применяется только по клику;
крестик или 14 секунд — гаснет.

## Провайдеры

Основной путь у пользователей — **облако Cloudflare Workers AI**: бесплатно навсегда без карты,
лучшая приватность (не учится на запросах), работает из России. Локальная модель — опция для
тех, кто не хочет отправлять мысли наружу.

Проверено запросами с реального адреса (2026-07-19):

**Заблокированы из России** (блокирует сам сервис по адресу, не РКН — обход бесполезен):
Groq, Cerebras, OpenRouter, Cohere, Gemini. Пользователю их не предлагать.

**Открыты:** Mistral, Together, DeepInfra, Fireworks, HuggingFace router, GigaChat, YandexGPT,
Cloud.ru, Cloudflare Workers AI.

**Бесплатно навсегда + приватно + доступно из России — ровно два:**

| Провайдер | Адрес | Особенности |
|---|---|---|
| Cloudflare Workers AI | `api.cloudflare.com/client/v4/accounts/{account_id}/ai/v1` | нужен и ключ, и Account ID; 10 тыс. запросов в день |
| HuggingFace Inference | `router.huggingface.co/v1` | работает без обхода; провайдера пинить суффиксом (`…:together`) ради приватности |

Российские (GigaChat, YandexGPT, Cloud.ru) — родной русский и оплата в рублях, но приватность
для **личных заметок** слабее: обучение по умолчанию либо отсутствие гарантий в оферте.

## Локальный движок

`llama-cpp-python`, лёгкая сборка (~6 МБ библиотеки, без лишнего). Два пака рядом с приложением:
`ai/engine-cpu` и `ai/engine-vulkan`, качаются по кнопке из служебного релиза с тегом `engines`.

Модель по умолчанию — из каталога в `app.py` (`AI_MODEL_CATALOG`). Выбор модели решался замерами:
модели на 0.5 млрд параметров путают вид и выдумывают; Gemma-2 роняла движок; 1.5 млрд заметно
грузит процессор. Ответ форсируется в JSON грамматикой по схеме — это надёжнее уговоров в промпте.

**Библиотеку можно втянуть в процесс только один раз.** Поэтому смена движка CPU⇄GPU после
попытки загрузки требует перезапуска приложения — приложение говорит об этом прямо.

## Грабли

- **Тестировать запись настроек на ПУСТОЙ папке.** Смена провайдера падала на свежей установке:
  папки `ai/` ещё нет, а конфиг пишется в неё. В деве папка уже существовала, потому не ловилось.
- **Ошибка загрузки модели раньше залипала на всю сессию:** флаг сбрасывался только при успехе, а
  интерфейс по нему решал, звать ли ИИ вообще. Теперь любое изменение настроек снимает приговор.
- **Готовность провайдера ≠ наличие ключа.** У Cloudflare нужен ещё Account ID; у локального —
  и движок, и файл модели. Переключатель обязан проверять факт готовности, а не намерение.
- **Обрыв закачки модели не бросает ошибку** — чтение просто возвращает пустоту. Размер сверяется
  с ожидаемым, иначе в папке оказывался битый файл под видом установленного.
- Прямая установка колеса `llama-cpp-python` с GitHub у КРОЛИКА режется провайдером — ставить
  с pythonhosted или скачивать вручную.
