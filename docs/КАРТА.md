# Карта кода «Мыслика»

Чтобы найти нужное место, не читая файлы целиком. Правишь код — правь карту в том же коммите.
Если карта разошлась с кодом — верить коду.

Пересобрать список символов: `python tools/dev.py map`
Найти место по слову: `python tools/dev.py где картинка` — печатает строки этой карты, символы
кода и селекторы стилей, где слово встречается. С него дешевле начинать, чем с поиска руками.

## Куда идти по симптому

Запрос обычно звучит не именами функций, а «вот это криво». Таблица переводит жалобу в адрес;
читать сразу указанное место, не открывая файл целиком.

| Жалоба звучит как | Смотреть |
|---|---|
| «строка захвата», «не понимает дату/тег», «предпросмотр» | `model.js: parseCapture`; чипы разбора — `main.js` (`#cap-preview`), стили `#cap-wrap`/`.cap-chip` |
| «граф тормозит / дёргается / жрёт видеокарту» | `graph.js`: `_tick` (условие ПОКОЯ), `_schedule`/`_wake`, `_drawMain`; замер — счётчик Ctrl+Shift+F |
| «подсветка ноды, наведение, соседи» | `graph.js`: `_hover`, `_родня`, в кадре — `n._нав` и массив `навед` |
| «связи: длина, прогиб, стрелки» | `graph.js`: `_easeBends`, физика в `_tick` (`restLen`, `lenMul`); длина до области — `it.arealen` |
| «области, хабы, пустышки» | `graph.js` `build()` (лучи к `hub_<id>`), `core.js: areaById`, панель — `views.js: renderNav` |
| «правая панель», «поля справа не так» | `views.js`: `renderAside`, `asideCard`, `строка()`, стили `.as-*` |
| «ширина панели, разделитель» | `views.js`: `asideMaxW`, `asideApplyWidth`, `wireSplitter`, стили `#aside`/`#splitter`/`#view` |
| «вкладка Сегодня / Задачи / Календарь» | `views.js`: `renderToday`, `renderTasks`, `renderCal`; стили `.home-*`, `.cal`, `.cd`, `.ev` |
| «окно правки, окно чтения, настройки» | `overlays.js`: `openItemEditor`, `openNoteReader`, `openSettings`; стили `.modal`, `.field`, `.modal-foot` |
| «срок, дедлайн, календарик» | `overlays.js`: `dueControlHtml`, `openDatePicker`, `wireDateControls`; стили `.date-btn`, `.dp*` |
| «поля ноды: текст, картинка, доска» | `fields.js`: `fieldsPanel` (панель), `fieldBlockHtml` (плитка), `fieldsLayout`/`fieldsFromLayout` (раскладка) |
| «вставка картинки, Ctrl+V» | `fields.js`: `fieldPasteTarget`, `fieldPasteWire`, `fieldsFitAuto`, `fieldImgHeight` |
| «полотно, доска, рисование» | `draw.js`: `openBoard`, `drawMount`, `drawFlush`; врезка в поле — `fields.js: fieldBoardStart` |
| «теги: цвет, значок, форма» | `core.js`: `tagStyle`, `tagInk` (цвет в смеси с темой), `itemTagStyle`; окно — `overlays.js: openTagManager` |
| «тема, цвета, тени» | `styles.css`: `:root` и `.light` (все переменные, включая `--sh`); переключение — `main.js: applyTheme` |
| «вёрстка поехала, вылезло, обрезано» | сначала замер: `dev.py run вёрстка`; затем правило в `styles.css` по классу из отчёта |
| «сохранение, откат, потеря данных» | `core.js`: `persist`, `writeNow`, `flushSave`, `undoStep`, `sanitizeState` |
| «обновление приложения, версия» | `main.js`: `autoCheckUpdate`, `showUpdateBanner`, `applyUpdateNow`; бэкенд — `app.py: check_update` |
| «ИИ, умный захват, отчёт» | `ai.js` (интерфейс) и `ai.py` (движок): `capture`, `report`, `status` |

Дальше по адресу из таблицы работает пайплайн из `CLAUDE.md` («Пайплайн правки»):
`search_graph` (где символ) → `trace_path inbound` (кто зовёт — до правки, а не после) →
`get_code_snippet` (тело) → `Edit`. Файл целиком не открывать.

Чем искать, если в таблице нет:
- **имя функции, «кто это зовёт», «что сломается»** — MCP `codebase-memory`. Отвечает адресом,
  а не текстом файла: `trace_path` по `head` за один ход показывает все пять вызывающих видов.
- **текст интерфейса, подпись, стиль, класс** — сразу `Grep`: символы кода граф знает, а строки
  и CSS — нет. То же для кусков, помеченных `parse_partial` в `index_status`: их границы
  ПЛАВАЮТ вместе с правками, номера строк наизусть не держать — спрашивать `index_status`.
- **свой код, написанный только что** — тоже `Grep`: в индекс он попадает не сразу, и граф
  честно отвечает «такого нет» про функцию, добавленную полчаса назад. Лечится `index_repository`.
- **«как это выглядит»** — дев-режим и замер (`dev.py run вёрстка`, счётчик кадров Ctrl+Shift+F),
  а не чтение стилей глазами.

## Общая схема

```
app.py       мост JS↔Python, окно, релиз/обновление, Telegram, ИИ-эндпоинты
ai.py        весь ИИ: провайдеры (облако/локальный llama.cpp), захват, отчёт
ui/index.html   порядок скриптов + ?v= (поднимать при каждой правке фронта)
ui/styles.css   вся вёрстка; блоки помечены комментариями (.draw-* — доска, .g-* — граф)
ui/js/*.js      фронт: классические скрипты, общая глобальная область, порядок важен
```

Порядок загрузки: **core → model → views → graph → overlays → draw → fields → ai → report → main**.
Ниже по списку можно звать всё, что выше. Наоборот — нет. Исключение — вызовы ИЗ ОБРАБОТЧИКОВ:
они случаются после загрузки всех файлов, поэтому `views.js` и `overlays.js` спокойно зовут
`fieldsPanel` из `fields.js`. Запрещено обратное — трогать чужие символы на верхнем уровне файла.

## Класс Graph (`graph.js`) — вкладка «Заметки»

- **Жизненный цикл:** `build()` собирает узлы, `_tick()` — кадр, `_schedule()` — ЕДИНСТВЕННОЕ
  место планирования кадра, `pause`/`resume`/`destroy`.
- **Фон:** WebGL — `_initBgGL`, `_drawBgGL`, самопроверка `_glSelfTest`. Контекст кэшируется
  на canvas (`_glCache`), есть обработчики потери и восстановления.
- **Взаимодействие:** `_wire` (указатель), `_openPop`/`_openLinkPop` (меню), `startLink`/`_linkTo`
  (связи), `_renderTray` (лоток неразобранных), `copySelection`/`pasteClip`.
- **Камера:** `_applyTransform`, `_fitView`, `_tweenView`, `_pt` (экран → мир).

## Доска полотна (`draw.js`)

- **Данные:** сцена ноды лежит в `S.boards[id ноды]` — `{elements, files, appState, fromFlow}`.
  Внутри ноды её нет намеренно: снимок отката сериализует `items` целиком.
- **Жизненный цикл:** `openBoard(it)` → `drawLoadLib` (ленивая загрузка вендора) →
  `drawSeedFromFlow` (разовый перенос старой схемы) → `drawMount`; закрытие — `drawClose`
  → `drawDestroy` (сначала стэш сцены, потом unmount и снятие слоя).
- **Запись:** `drawTouch` (дебаунс 900 мс) → `drawStash` → `persist(true)`. Холостые записи
  отсекает отпечаток `drawFingerprint` (версия сцены + срез настроек инструмента).
  `drawFlush()` дожимает немедленно — зовётся при закрытии окна из `main.js`.
- **Перенос схем:** `flowToExcalidraw` — блоки становятся прямоугольниками (различия через
  скругление, пунктир, цвет обводки), стрелки считаются от края к краю, картинки уезжают
  в `files`, видео заменяется рамкой-заглушкой (в Excalidraw такого типа нет).
- **Настройки вендора:** `drawProps` — своё меню (`drawMenu`), тема из `S.settings.theme`,
  `onLinkOpen` уводит клик по перенесённой привязке в `openItemSmart`.

## app.py

- **Мост:** класс `Api` — всё, что зовётся из JS как `window.pywebview.api.<метод>`.
  Данные: `load`, `save`, `backup`, `export_data`, `import_data`.
  Окно: `win_min`, `win_max`, `win_close`, `win_drag`. Обновление: `check_update`, `apply_update`.
  Telegram: `telegram_check` + `telegram_ack`. ИИ: `ai_*` — тонкие обёртки над `ai.py`.
- **Окно и система:** `_find_own_window` (по PID, не по заголовку), `_set_taskbar_icon`,
  `_set_taskbar_button_icon`, `_enable_frameless_resize`, `_selftest`.
- **Старт:** `main()` — каталоги, бэкап, ИИ, уборка `.part`, создание окна, `webview.start(icon=…)`.

## ai.py

- **Конфигурация:** `_load_config`/`_save_config`, провайдер `_read_provider`/`set_provider`,
  движок `set_backend`, модели `list_models`/`set_model`/`delete_model`.
- **Состояние:** `status()` — единственный источник правды для фронта (`available`, `reason`).
- **Работа:** `capture` (мысль → поля) и `report` (выделенное → текст), у каждой две ветки:
  `_*_local` (llama.cpp) и `_*_api` (облако). У `report` два формата: `mode="prose"`
  (`_REPORT_INSTRUCT`) и `mode="list"` — список «владелец — папка» (`_LIST_INSTRUCT`, температура 0.1).
- **Загрузка модели:** `_get_llm` — ленивая, помнит фактически импортированный движок.

## Данные

`data/planner.json`: `{v, areas[], items[], links[], tags[], boards{}, media{}, templates[], settings{}}`.
`boards` — доски полотен по id ноды: `{elements[], files{}, appState{}, fromFlow}`; доска ПОЛЯ
лежит там же под ключом `fld_<id поля>`.
`media` — картинки полей: `"m_…"` → data-URL. `templates` — шаблоны нод:
`{id, name, kind, tags[], fields[{type,name,gw,gh}]}`, выбранный по умолчанию — в `settings.template`.
`links` — массивы `[a, b, длина?]`; хабы областей — `hub_<id>`.
Элемент: `id, kind(task|note|flow), title, body, area, status, due, repeat, priority, tags[],
created, updated, done, x, y, pin, parent, color`; `arealen` — длина нити до своей области
(её в `links` нет, граф строит луч сам); у схем — `flow`.
Именованные поля — `fields[{id, type(text|image|board), name, value|media, gw, gh, br, st, gwm, off, nofit}]`:
`gw` — доля строки из 12 и свойство КОЛОНКИ, `gh` — высота плитки в пикселях, `br` — начинает
строку, `st` — лежит под предыдущей в той же колонке, `gwm` — ширину строки задали руками,
`off` — свёрнуто, `nofit` — ОТКАЗ от авто-высоты картинки (по умолчанию она включена).
Ключа `fields` нет вовсе, пока у ноды нет полей.
