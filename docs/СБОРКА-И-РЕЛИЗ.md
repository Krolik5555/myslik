# Сборка и релиз

Кратко: `tools/release.ps1` делает всё сам. Вручную собирать не нужно — только когда надо
проверить сборку до публикации.

## Что где

- Репозиторий: https://github.com/Krolik5555/myslik — **публичный** (иначе кнопка «Обновить»
  у других людей не работала бы без токена). Слаг вшит в `app.py` (`GH_REPO_SLUG`).
- `gh` стоит портативно: `C:\Users\KROLIK\tools\gh\bin\gh.exe` — **в PATH его нет**.
- Сборка: `Myslik.spec`, PyInstaller в `.venv`. Имя exe латиницей (`Myslik.exe`), окно и
  интерфейс — кириллицей («Мыслик»).

## Порядок релиза

1. **Версия в ТРЁХ местах, одинаковая:** `app.py APP_VERSION` (она авторитетна для
   автообновления и тега), блок `side-ver` в `ui/index.html`, первая строка
   `packaging/ЧИТАТЬ.txt`. Менялся фронт — поднять `?v=` в `index.html`.
2. **Тур «что нового» — под ЭТОТ релиз** (`ui/js/main.js`). Обязателен для каждого выпуска:
   - `ТУР_ID` = номер выпускаемой версии (он же id отметки `settings.tourSeen` и он же виден
     в плашке);
   - `ТУР` переписан под то, что реально изменилось. Прошлый текст НЕ оставлять: человек
     обновился ради этой версии, а не позапрошлой;
   - новая функция → шаг с `цель:"#селектор кнопки"` (подсветит её и покажет стрелкой) и, если
     есть что показать, `демо:true` с записями в `ui/media`. Мелкие правки → просто списком,
     без демонстрации, `ТУР_ДЕМО` тогда не нужен;
   - клипы прошлого релиза из `ui/media` удалить, иначе они уедут в сборку мёртвым грузом
     (в `Myslik.spec` папка `ui` берётся целиком);
   - записи готовить так: `ffmpeg -i исходник.mp4 -vf "crop=…,fps=30,scale=440:-2" -an
     -c:v libvpx-vp9 -crf 36 -b:v 0 -row-mt 1 "ui/media/имя.webm"` — 5 секунд укладываются в
     ~100 КБ. GIF не брать: те же секунды весят мегабайты и полосят на тёмном фоне;
   - проверить `dev.py run тур` — он стережёт порядок «плашка → по кнопке разбор», место плашки,
     номер версии в ней и то, что она показывается один раз.
3. Заметки к релизу — в UTF-8 файл.
4. Снять зависшие процессы (держат файлы `_internal`, сборка падает с отказом в доступе).
   ВАЖНО: из исходников приложение зовётся **pythonw**, а не `Myslik` — искать по командной
   строке, иначе решишь, что всё закрыто, а работающая копия перезапишет `data/planner.json`
   из своей памяти (так уже терялся сброс отметки тура):
   `Get-CimInstance Win32_Process | ? { $_.CommandLine -match 'app.py|Myslik' }`.
   Чужие процессы не убивать — просить КРОЛИКА закрыть окна.
5. `powershell -File tools\release.ps1 -Version X.Y.Z -NotesFile путь.md`
6. Проверить: `gh release view vX.Y.Z -R Krolik5555/myslik --json assets`.

Перед публикацией полезно собрать exe отдельно и запустить `PLANNER_SELFTEST=1` — скрипт
публикует сразу после сборки, промежуточной проверки в нём нет.

## Нумерация версий

- Третья цифра `1.5.X` — новый набор изменений или фича.
- Четвёртая `1.5.0.X` — **только заплатка** поверх уже выпущенного.

## Как работает обновление в приложении

`check_update()` читает `releases/latest` публичным API и сравнивает `APP_VERSION` с тегом.
`apply_update()` (только в собранном виде) качает архив, распаковывает в `_update/new`, пишет
ASCII-bat во временную папку, пути передаёт через переменные окружения, закрывает окно; bat
дожидается выхода процесса, подменяет `_internal` и exe (с промежуточной папкой, бэкапом и
откатом) и перезапускает. **Папку `data/` не трогает никогда** — её нет в архиве.

## Грабли, проверенные на практике

- `release.ps1` держать **только в ASCII**: PowerShell 5.1 читает файл без BOM как ANSI, и
  кириллица валит разбор. Кириллическое имя `ЧИТАТЬ.txt` решено через `tools/place_readme.py`.
- `$args` — автопеременная PowerShell, не использовать как своё имя.
- `print` в `place_readme.py` — только ASCII: перенаправленный вывод здесь в cp1252.
- COLLECT с `--noconfirm` сносит всю папку `release/Myslik/` — `ЧИТАТЬ.txt` кладётся заново
  после сборки.
- В сборке пути «frozen-aware»: ресурсы из `sys._MEIPASS/ui` (только чтение), а данные — **рядом
  с exe** (`data/planner.json`, `data/backups/`). Приложение портативное: переносишь папку —
  заметки с тобой.
- Заголовок окна «Мыслик» синхронизирован с поиском окна и включением ресайза краёв. Меняешь
  заголовок — проверь оба места.
- Локальные модели ИИ и движки **не вшиты** в сборку, качаются по кнопке. Движки лежат в
  служебном GitHub-релизе с тегом `engines`: у части пользователей `release-assets` режется
  провайдером, поэтому важно, чтобы источник был доступен.
