# «Мыслик» — обзор для внешнего собеседника

Этот файл нужен, чтобы обсуждать дизайн приложения с ИИ, у которого нет доступа к коду.
Он описывает, что за продукт, как он устроен и какие ограничения нельзя нарушать.
Файл самодостаточный: ничего, кроме него, показывать не требуется.

---

## 1. Что это

**Мыслик** — личный планер одного человека (не командный продукт, не SaaS). Настольное
приложение для Windows, работает полностью офлайн, данные лежат одним JSON-файлом рядом
с программой. Автор — 3D-художник и режиссёр-любитель: планирует съёмки, монтаж, аддоны
для Blender, личные проекты.

Главная идея: **мысль важнее формы**. Сначала бросил мысль одной строкой — потом разобрал.
Задачи, заметки и схемы не разделены на изолированные разделы, а связаны в одну паутину.

Приложение русскоязычное. Интерфейс, тексты и подсказки — только по-русски.

---

## 2. Экраны

Слева вертикальное меню на шесть видов, переключение мышью или клавишами 1–6.

| Вид | Что показывает |
|---|---|
| **Сегодня** | Домашний экран-дашборд: кольцо выполненного за день, серия дней подряд, спарклайн недели, баланс по областям, что просрочено |
| **Задачи** | Плоско-иерархический список с фильтром по областям и тегам; выполненные уезжают вниз |
| **Заметки** | Граф-паутина: ноды и связи, физическая раскладка, зум колесом, фон со звёздами и параллаксом. Есть альтернативный режим «Список» карточками |
| **Полотно** | Доска для рисования от руки (движок Excalidraw), открывается на весь экран поверх приложения. У каждой ноды-полотна своя доска |
| **Папки** | Дерево проектов с привязкой к настоящим папкам на диске: клик — открывается проводник |
| **Календарь** | Месяц, задачи перетаскиваются по дням, повторяющиеся показаны призраками |
| **Корзина** | Мягко удалённое, можно вернуть |

Сверху во всю ширину — **строка быстрого захвата**. Всегда на месте, на любом виде.

---

## 3. Ключевые механики

**Быстрый захват.** Одна строка, Enter — и мысль в системе. Разбирает прямо из текста:
`#область/#тег`, даты (`завтра`, `пн`, `25.06`), повторы (`каждый день`), `!приоритет`,
`*заметка` (иначе создаётся задача). Есть режим «умного захвата» через локальную или облачную
языковую модель: она раскладывает свободную фразу по полям, но это опция, по умолчанию выключена.

**Граф вместо папок.** Основная структура — не дерево, а связи. Нода — заметка, задача или
полотно. Связи рисуются жестом Alt+протяжка. Мысль без координат считается «неразобранной» и
лежит в лотке сбоку от графа, пока её не вытянут на холст.

**Области** — крупные сферы жизни (Работа, Аддоны, Личное). У каждой иконка и цвет, показывают
процент выполненного.

**Теги со стилем** — тег может задавать ноде размер, цвет, иконку и форму. Так «проект»
отличается от рядовой заметки визуально, без отдельной сущности в данных.

**Полотно = доска.** Каждая нода типа «полотно» открывает собственный холст Excalidraw:
фигуры, стрелки с привязкой к фигурам, подписи рукописным шрифтом, вставка картинок,
своя история отмены. Сохраняется само.

**Прочее:** таймер фокуса, отчёт по выделенным элементам (можно через ИИ), захват заметок
с телефона через своего Telegram-бота, обновление приложения изнутри, экспорт/импорт всего
состояния одним файлом, авто-бэкапы.

## 4. Как это выглядит сейчас

**Чёрно-белый минимализм со свечением.** Цвет в интерфейсе — только смысловой: область,
срочность, статус. Украшательского цвета нет принципиально.

- Фон тёмной темы — чистый чёрный (`#000`), поверхности — `#0c0c0e`, `#161618`, `#1f1f22`.
- Акцент в тёмной теме — белый; в светлой — чёрный.
- Границы тонкие и почти прозрачные: `0.5px` белого с прозрачностью 13–40 %.
- Скругления: 8 / 11 / 14 px в зависимости от размера элемента.
- Шрифт интерфейса — Segoe UI Variable Text (системный Windows).
- Свечение (`glow`) — мягкая подсветка вокруг активных элементов, регулируется в настройках.
- Есть полноценная светлая тема, переключается в один клик.
- Иконки — набор Tabler, лежат локально.

**Окно.** Безрамочное, полоса заголовка рисуется системой (40 px) ради корректной работы
Aero Snap. Размер по умолчанию 1200×800, минимальный — 920×640.

**Анимации** сдержанные: плавное появление карточек при смене вкладки, мягкие переходы
цвета и тени. Ничего прыгающего.

## 5. Технические рамки (влияют на дизайн)

Это не пожелания, а ограничения среды. Предложения, которые их нарушают, реализовать нельзя.

- **Фронтенд — ванильные HTML/CSS/JS без сборщика.** Никаких React/Vue/Tailwind в самом
  приложении: модули подключаются обычными `<script>`, общая глобальная область.
  (Исключение — встроенный Excalidraw, он собран в один файл заранее.)
- **Страница грузится по `file://`**, поэтому ES-модули, динамические импорты и сетевые
  запросы к CDN недоступны. Всё — локальными файлами.
- **Движок — WebView2 (Chromium)**, то есть современный CSS доступен: flex, grid,
  `color-mix`, `:has()`, кастомные свойства.
- **Приложение работает офлайн.** Никаких внешних шрифтов, аналитики, облачных картинок.
- **Экран один, окно небольшое.** Мобильной версии нет и не планируется, но интерфейс должен
  выживать при 920×640.
- **Один пользователь.** Ни совместного редактирования, ни ролей, ни онбординга для новичков.

## 6. Что уже отвергнуто (не предлагать заново)

- **Канбан-доска со статусами** — автор организует работу через граф, а не через колонки.
- **Отдельный «Инбокс»** — заменён понятием «нода без координат», лежит в лотке графа.
- **Цвет ради красоты** — палитра приглушённая, цвет только смысловой.
- **Новые сущности там, где хватает связи в графе** — сознательный принцип экономии структуры.
- **Показ удалённого в счётчиках и списках** — корзина не влияет на статистику.
- **Собственный редактор блок-схем** — был, удалён в пользу Excalidraw.

## 7. О чём имеет смысл говорить

Живые темы, где мнение со стороны полезно:

1. **Домашний экран «Сегодня».** Сейчас это набор виджетов: кольцо дня, серия, ритм недели,
   баланс областей, просроченное. Вопрос — что из этого действительно помогает начать день,
   а что просто украшает.
2. **Граф как основной способ навигации.** Он красив, но найти конкретную ноду в большой
   паутине сложнее, чем в списке. Как совместить обзорность графа и скорость списка.
3. **Переход между режимами.** Полотно открывается поверх всего и прячет навигацию.
   Это удобно для рисования, но выбивает из контекста.
4. **Плотность интерфейса.** Много воздуха и тонких границ — читается спокойно, но на
   маленьком окне места мало.
5. **Свечение и «космический» фон графа.** Нравится автору, но спорно с точки зрения
   утомляемости при долгой работе.
6. **Связь доски с задачами.** Сейчас нарисованное на полотне ничего не знает об элементах
   планера. Стоит ли связывать и как, чтобы не превратить это в громоздкую систему.

## 8. Как отвечать автору

- По-русски, без англицизмов там, где есть русские слова.
- Сначала одна главная мысль или причина, потом детали. Списки из десяти равнозначных
  вариантов не помогают.
- Конкретика важнее общих принципов: не «улучшите иерархию», а «этот блок убрать, этот
  поднять, вот почему».
- Помнить, что это личный инструмент одного человека: доводы вида «пользователи привыкли»
  или «так делают в Notion» весят мало. Важнее, работает ли это для конкретных привычек.
